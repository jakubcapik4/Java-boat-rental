# Boat Rental Management System

A Java desktop application developed as a university project for managing boat rentals and vessel inventory.

## Project Overview

The application provides a graphical interface for managing different types of vessels and rental records. It demonstrates object-oriented programming concepts and basic data persistence.

## Features

- Manage different types of vessels.
- View and filter available vessels.
- Create and manage rental records.
- Calculate rental prices.
- Generate rental agreements.
- Save and load application data using CSV files.

## Technologies

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- CSV file handling
- Eclipse IDE

## Project Structure

- `src/` — Java source code, including the main application, vessel classes, and graphical interface.
- `.project` and `.classpath` — Eclipse project configuration files.
- `.settings/` — Eclipse-specific project settings.

## Getting Started

1. Install a compatible Java Development Kit (JDK).
2. Clone or download this repository.
3. Import the project into Eclipse as an existing Java project.
4. Open `pozicovna.gui.PozicovnaGUI` and run it as a Java application.

The application may require additional configuration depending on the Java version and local environment.
